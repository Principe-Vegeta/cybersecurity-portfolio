# Learning Map

This portfolio is organized around practical skills represented in my current cybersecurity study notes.

## Linux and command line

- File and directory navigation
- Users and permissions
- Package management
- Services
- File discovery
- Text processing with `grep`, `cut`, `awk`, and `sed`

## Windows fundamentals

- Command Prompt navigation
- Network configuration with `ipconfig`
- Network connections with `netstat`
- Process inspection with `tasklist`
- User management with `net user`

## Bash scripting

- Shebangs and executable permissions
- Variables and positional arguments
- `if`, `elif`, `case`
- `for` and `while` loops
- Command substitution
- Exit codes
- Output redirection

## Networking

- ICMP host discovery
- TCP ports and SYN responses
- DNS concepts
- HTTP request/response basics
- Network traffic inspection

## Python networking

- `socket`
- TCP connection testing
- Command-line arguments
- Timeouts

## Security tooling

- Wireshark
- tcpdump
- Netcat/Ncat
- hping3
- curl
- wget
