# Security Labs

Hands-on cybersecurity laboratory exercises developed during my security training.

These labs focus on reconnaissance, web enumeration, HTTP analysis, information gathering, and security observations.

All activities were performed in authorized training environments.

## Learning Approach

The objective of these labs is to understand the methodology behind reconnaissance and enumeration rather than simply memorize commands.

The workflow I am practicing is:

Reconnaissance → Enumeration → Validation → Analysis → Documentation → Defensive recommendations

## Responsible Use

These techniques are intended only for systems I own or environments where I have explicit authorization to test.
