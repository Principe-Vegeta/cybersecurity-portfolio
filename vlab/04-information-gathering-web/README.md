# Information Gathering — Web Information Leakage

## Overview

This laboratory focused on identifying information exposed through publicly accessible web content.

## Objective

Practice information gathering through direct web inspection and basic command-line text processing.

## Methodology

1. Identify the authorized scope.
2. Inspect publicly accessible web content.
3. Identify potentially useful information.
4. Extract relevant patterns using command-line tools.
5. Normalize and organize the collected data.
6. Evaluate the potential security impact.

## Tools

- cURL
- grep
- Regular expressions
- sort
- sed
- tr

## Key Concepts

- Information gathering
- Information leakage
- OSINT fundamentals
- Regular expressions
- Command-line text processing

## Lessons Learned

Automated OSINT tools are useful, but manual web inspection remains an important skill.

Simple Linux command-line pipelines can extract and normalize structured information efficiently.

Publicly exposed organizational information can increase the risk of targeted phishing and other social-engineering attacks.

## Defensive Perspective

Organizations should:

- Minimize unnecessary public information exposure.
- Review contact information published on websites.
- Avoid exposing internal or sensitive organizational details.
- Monitor publicly accessible resources.
- Include information exposure in security assessments.

## Ethical Use

This laboratory was performed in an authorized training environment.

Real target information, personal data, credentials, and laboratory answers are intentionally excluded from this portfolio.
